Guide
circuit.js

circuit.js est le fichier qui contient la librairie de circuits prédéfinis du simulateur. C'est lui qui permet de partir d'un exemple fonctionnel au lieu d'une plaque vide.

Ce guide explique ce que contient le fichier, comment l'utiliser, comment y ajouter un circuit, et comment éviter les erreurs les plus courantes.

Rôle du fichier

Le simulateur charge circuit.js au démarrage. Le fichier expose une constante globale, généralement nommée CIRCUITS, qui contient la liste des circuits disponibles dans la librairie.

Chaque fois que l'utilisateur clique sur « Charger un exemple » ou « Bibliothèque », le simulateur lit cette liste, construit la fenêtre, et attend qu'un circuit soit choisi. Charger un circuit revient à le reconstruire sur la plaque, composant par composant, connexion par connexion.

Le fichier est chargé avant simulateur.js. Il ne contient aucune logique, seulement des données. Aucune fonction, aucun calcul. C'est un catalogue.

Structure générale

Le fichier contient un tableau d'objets. Chaque objet représente un circuit. La structure ressemble à ceci : 

const CIRCUITS = [
  {
    id: 'serie',
    nom: 'Circuit série',
    description: 'Une pile et deux résistances en série.',
    categorie: 'Bases',
    composants: [
      { type: 'battery', x: 100, y: 200, value: 12 },
      { type: 'resistor', x: 300, y: 200, value: 100 },
      { type: 'resistor', x: 500, y: 200, value: 200 }
    ],
    connexions: [
      { de: 0, borne: 0, vers: 1, borneCible: 0 },
      { de: 1, borne: 1, vers: 2, borneCible: 0 },
      { de: 2, borne: 1, vers: 0, borneCible: 1 }
    ]
  },
  /* autres circuits... */
];

Trois sections composent chaque circuit. Les informations générales (identifiant, nom, description, catégorie), la liste des composants, et la liste des connexions entre leurs bornes.

Un circuit

Chaque circuit contient six champs :

Champ Rôle Exemple
id Identifiant unique, en minuscules, sans espaces. serie
nom Titre affiché dans la fenêtre de la librairie. Circuit série
description Phrase courte qui apparaît sous le nom. Une pile et deux résistances en série.
categorie Groupe auquel le circuit appartient. Sert au rangement. Bases
composants Tableau des composants qui forment le circuit. Voir section suivante.
connexions Tableau des connexions entre les bornes. Voir section après.

L'identifiant doit être unique dans tout le fichier. Deux circuits ne peuvent pas partager le même. Si cela arrive, seul le premier sera chargé.

Les composants

Chaque composant est décrit par quatre champs : 

{ type: 'battery', x: 100, y: 200, value: 12 }
Champ Rôle
type Nature du composant. Doit correspondre à un type existant.
x Position horizontale, en pixels depuis le bord gauche de la plaque.
y Position verticale, en pixels depuis le bord supérieur.
value Valeur numérique. Tension en volts pour une pile, résistance en ohms pour une résistance. Peut être omis pour les composants sans valeur.

Types de composants disponibles

Type Nom Valeur Unité
batteryPileTensionV
resistorRésistanceRésistanceΩ
lampLampeRésistance interneΩ
switchInterrupteur0 ouvert, 1 fermé—
ledLEDTension de seuilV
fuseFusibleCourant maximalA
motorMoteurRésistance interneΩ
ammeterAmpèremètreAucune—
voltmeterVoltmètreAucune—
wireFilAucune—

Si un type n'est pas reconnu, le simulateur crée une résistance par défaut. Le circuit se charge quand même, mais avec un composant incorrect.

Conseil : les positions sont en pixels sur la plaque. Un pas de 80 pixels entre deux composants alignés donne une disposition lisible. Ne place pas deux composants au même endroit, ils se superposeraient.

Les connexions

Chaque connexion relie deux bornes. Elle est décrite par quatre champs : 

{ de: 0, borne: 0, vers: 1, borneCible: 0 }
Champ Rôle
de Indice du premier composant dans le tableau composants. Le premier a l'indice 0, le deuxième l'indice 1, et ainsi de suite.
borne Numéro de la borne du premier composant. 0 pour la borne gauche, 1 pour la borne droite.
vers Indice du deuxième composant.
borneCible Numéro de la borne du deuxième composant.

Exemple concret

Reprenons le circuit série. Trois composants : une pile (indice 0), une résistance (indice 1), une résistance (indice 2). 

connexions: [
  { de: 0, borne: 0, vers: 1, borneCible: 0 },  // pile+ vers R1 gauche
  { de: 1, borne: 1, vers: 2, borneCible: 0 },  // R1 droite vers R2 gauche
  { de: 2, borne: 1, vers: 0, borneCible: 1 }   // R2 droite vers pile−
]

Ces trois connexions forment une boucle fermée. Le courant peut circuler de la pile vers les deux résistances puis revenir à la pile.

Attention : chaque borne ne peut recevoir qu'une seule connexion. Si tu écris deux lignes qui utilisent la même borne du même composant, la deuxième sera ignorée.

Ouvrir la librairie

Dans le simulateur, deux façons d'accéder à la librairie.

  1. Clique sur Bibliothèque dans la barre d'outils du haut. Une fenêtre apparaît avec la liste des circuits rangés par catégorie.
  2. Ou depuis une fiche de TP, clique sur Charger l'exemple. Le simulateur s'ouvre avec le circuit déjà en place.

La fenêtre se ferme avec la croix, en cliquant en dehors, ou avec Échap.

Charger un circuit

Charger un circuit remplace le contenu actuel de la plaque. Si tu as construit quelque chose que tu veux garder, sauvegarde-le avant.

  1. Ouvre la librairie.
  2. Repère le circuit dans la liste.
  3. Clique sur son nom.
  4. La fenêtre se ferme, le circuit apparaît sur la plaque.
  5. Clique sur Simuler pour voir le résultat.

Les composants apparaissent à leurs positions prédéfinies. Les bornes déjà connectées sont vertes.

Exporter son propre circuit

Après avoir construit un circuit qui te plaît, tu peux l'exporter pour l'ajouter à la librairie.

  1. Construis le circuit sur la plaque.
  2. Clique sur Exporter dans la barre d'outils.
  3. Un fichier JSON est téléchargé.
  4. Ouvre ce fichier pour voir sa structure.

Le fichier contient les mêmes informations que circuit.js, mais avec les identifiants réels des composants au lieu des indices. 

{
  "version": "1.0",
  "date": "2025-10-09T14:30:00Z",
  "components": [
    { "id": "comp_1", "type": "battery", "x": 100, "y": 200, "value": 9 },
    { "id": "comp_2", "type": "resistor", "x": 300, "y": 200, "value": 100 }
  ],
  "connections": [
    { "from": "comp_1", "fromTerm": 0, "to": "comp_2", "toTerm": 0 },
    { "from": "comp_2", "fromTerm": 1, "to": "comp_1", "toTerm": 1 }
  ]
}

Pour intégrer ce circuit à la librairie, il faut convertir les identifiants en indices. Le premier composant du tableau devient l'indice 0, le deuxième l'indice 1, et ainsi de suite. Voir la section suivante.

Ajouter un circuit à la librairie

Pour ajouter un circuit, ouvre circuit.js dans un éditeur de texte et ajoute une entrée à la fin du tableau, avant le crochet fermant.

Voici un exemple complet, prêt à copier :

{
  id: 'parallele',
  nom: 'Circuit parallèle',
  description: 'Une pile et deux résistances en parallèle.',
  categorie: 'Bases',
  composants: [
    { type: 'battery', x: 100, y: 200, value: 12 },
    { type: 'resistor', x: 350, y: 120, value: 100 },
    { type: 'resistor', x: 350, y: 280, value: 100 }
  ],
  connexions: [
    { de: 0, borne: 0, vers: 1, borneCible: 0 },
    { de: 0, borne: 0, vers: 2, borneCible: 0 },
    { de: 1, borne: 1, vers: 0, borneCible: 1 },
    { de: 2, borne: 1, vers: 0, borneCible: 1 }
  ]
}

Vérifie que l'identifiant est unique. Vérifie que les bornes utilisées ne sont pas déjà prises. Enregistre le fichier, recharge la page du simulateur, et le nouveau circuit apparaîtra dans la librairie.

Méthode recommandée : construis d'abord ton circuit dans le simulateur, exporte-le, puis recopie le contenu du fichier JSON dans circuit.js en convertissant les identifiants en indices. Tu éviteras les erreurs de coordonnées et de bornes.

Erreurs fréquentes

Symptôme Cause probable Correction
Le circuit ne s'affiche pas Erreur de syntaxe JavaScript, une virgule manquante. Ouvre la console F12, corrige la ligne indiquée.
Le circuit s'affiche partiellement Les indices de connexion dépassent la taille du tableau composants. Vérifie que chaque de et vers correspond à un composant existant.
Deux composants se superposent Positions identiques en x et y. Décale d'au moins 80 pixels.
Un composant apparaît comme une résistance Le type n'existe pas. Vérifie l'orthographe dans la liste des types.
La simulation donne des valeurs absurdes Une borne reçoit plusieurs connexions, ou le circuit n'est pas fermé. Trace le circuit à la main sur papier avant de le coder.
Le circuit apparaît dans la mauvaise catégorie Le champ categorie diffère des autres. Utilise exactement les mêmes chaînes de caractères.
Charger un circuit plante le simulateur Une valeur est négative ou nulle là où il faut une valeur positive. Résistances et tensions doivent être strictement positives.

Intégration au simulateur

Le simulateur expose quelques méthodes qui agissent sur la librairie. Elles sont utilisables depuis la console F12 pour tester.

Méthode Rôle
Simulateur.loadFromLibrary(id) Charge le circuit dont l'identifiant correspond.
Simulateur.openLibrary() Ouvre la fenêtre de la librairie.
CIRCUITS.length Nombre total de circuits dans la librairie.
CIRCUITS[0] Premier circuit du tableau, pour inspection.
CIRCUITS.map(c => c.id) Liste de tous les identifiants disponibles.

Pour tester un chargement rapide, ouvre la console du simulateur et tape : 

Simulateur.loadFromLibrary('serie')

Si le circuit existe, il apparaît immédiatement sur la plaque. Sinon, un message d'erreur t'indique que l'identifiant n'existe pas.

Ordre de chargement

Dans simulateur.html, circuit.js doit être chargé avant simulateur.js. L'ordre correct est : 

<script src="js/circuit.js"></script>
<script src="js/simulateur.js"></script>

Si l'ordre est inversé, le simulateur ne trouvera pas les données et la librairie sera vide.

Raccourcis

ÉchapFermer la fenêtre de la librairie
EntréeSimuler le circuit chargé
Ctrl + SSauvegarder le circuit en cours
Ctrl + OOuvrir la liste des circuits sauvegardés
Ctrl + Shift + IOuvrir la console développeur

Ne confonds pas les circuits de la librairie et les circuits sauvegardés localement. Les premiers viennent de circuit.js, les seconds de ton propre travail, stockés dans le navigateur.
