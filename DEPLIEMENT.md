# Guide de déploiement

## Option 1 : GitHub Pages (recommandé)

1. Créer un dépôt GitHub nommé `labo-virtuel`
2. Pousser le code :
   ```bash
   git init
   git add .
   git commit -m "Version initiale"
   git branch -M main
   git remote add origin https://github.com/[username]/labo-virtuel.git
   git push -u origin main
   ```
