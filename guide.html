Ce laboratoire contient quatre parcours, onze modules, vingt-et-un cours, un simulateur de circuits, une librairie d'exemples prêts à charger et un quiz par module. Voici comment tout s'articule.

Modules et cours

Onze modules sont rangés en quatre catégories.

Fondamentaux
Courant continu et courant alternatif. Ces deux modules disposent d'un simulateur et de fiches de TP.
Énergie
Systèmes triphasés et transformateur. Simulateur pour la partie triphasé.
Analogique
Électronique fondamentale, semi-conducteurs, amplification, filtrage.
Numérique
Logique numérique et transmission.

Les modules « existants » affichent une liste de TP numérotés. Les modules « cours » affichent une liste de chapitres, chacun renvoyant vers une page dédiée avec formule, explication, origine et schémas.

Utiliser circuit.js

circuit.js contient la librairie de circuits prédéfinis. C'est ce fichier qui permet de partir d'un exemple fonctionnel plutôt que d'une plaque vide.

Chaque fois que tu cliques sur « Bibliothèque » ou sur « Charger un exemple » dans une fiche de TP, le simulateur lit circuit.js, affiche la liste, et reconstruit le circuit choisi composant par composant.

Important : le fichier ne contient aucune logique, seulement des données. C'est un catalogue. Toute la mécanique de construction se fait dans simulateur.js.

Ouvrir la librairie

Deux moyens d'y accéder depuis le simulateur.

  1. Clique sur Bibliothèque dans la barre d'outils du haut. Une fenêtre apparaît avec la liste des circuits rangés par catégorie.
  2. Ou depuis une fiche de TP, clique sur Charger l'exemple. Le simulateur s'ouvre avec le circuit déjà en place.

La fenêtre se ferme avec la croix en haut à droite, en cliquant en dehors, ou avec Échap.

Charger un circuit

Charger un circuit remplace le contenu actuel de la plaque. Si tu as construit quelque chose que tu veux garder, sauvegarde-le avant.

  1. Ouvre la librairie.
  2. Repère le circuit voulu dans la liste.
  3. Clique sur son nom.
  4. La fenêtre se ferme, le circuit apparaît sur la plaque.
  5. Clique sur Simuler pour voir le résultat.

Les composants apparaissent à leurs positions prédéfinies. Les bornes déjà connectées sont marquées en vert.

Tu peux aussi tester un chargement direct depuis la console développeur (F12) : 

Simulateur.loadFromLibrary('serie')

Si l'identifiant existe, le circuit s'affiche immédiatement. Sinon, un message indique que le circuit est introuvable.

Structure du fichier

circuit.js contient un tableau d'objets. Chaque objet représente un circuit. Voici un exemple complet : 

{
  id: 'serie',
  nom: 'Circuit série',
  description: 'Une pile et deux résistances en série.',
  categorie: 'Bases',
  composants: [
    { type: 'battery',  x: 100, y: 200, value: 12 },
    { type: 'resistor', x: 300, y: 200, value: 100 },
    { type: 'resistor', x: 500, y: 200, value: 200 }
  ],
  connexions: [
    { de: 0, borne: 0, vers: 1, borneCible: 0 },
    { de: 1, borne: 1, vers: 2, borneCible: 0 },
    { de: 2, borne: 1, vers: 0, borneCible: 1 }
  ]
}

Les six champs d'un circuit

Champ Rôle
id Identifiant unique, en minuscules, sans espaces.
nom Titre affiché dans la fenêtre de la librairie.
description Phrase courte qui apparaît sous le nom.
categorie Groupe auquel le circuit appartient. Sert au rangement.
composants Tableau des composants qui forment le circuit.
connexions Tableau des connexions entre les bornes.

Les quatre champs d'un composant

{ type: 'battery', x: 100, y: 200, value: 12 }
Champ Rôle
type Nature du composant. Doit correspondre à un type existant.
x Position horizontale en pixels depuis le bord gauche de la plaque.
y Position verticale en pixels depuis le bord supérieur.
value Valeur numérique. Tension en volts pour une pile, résistance en ohms pour une résistance. Peut être omis pour les composants sans valeur.

Les quatre champs d'une connexion

{ de: 0, borne: 0, vers: 1, borneCible: 0 }
Champ Rôle
de Indice du premier composant dans le tableau composants. Le premier a l'indice 0.
borne Numéro de la borne du premier composant. 0 pour la gauche, 1 pour la droite.
vers Indice du deuxième composant.
borneCible Numéro de la borne du deuxième composant.

Attention : chaque borne ne peut recevoir qu'une seule connexion. Si deux lignes utilisent la même borne du même composant, la deuxième est ignorée.

Ajouter un circuit

Pour ajouter un circuit, ouvre circuit.js dans un éditeur de texte et insère une entrée à la fin du tableau, avant le crochet fermant.

Voici un exemple complet, prêt à copier :

{
  id: 'parallele',
  nom: 'Circuit parallèle',
  description: 'Une pile et deux résistances en parallèle.',
  categorie: 'Bases',
  composants: [
    { type: 'battery',  x: 100, y: 200, value: 12 },
    { type: 'resistor', x: 350, y: 120, value: 100 },
    { type: 'resistor', x: 350, y: 280, value: 100 }
  ],
  connexions: [
    { de: 0, borne: 0, vers: 1, borneCible: 0 },
    { de: 0, borne: 0, vers: 2, borneCible: 0 },
    { de: 1, borne: 1, vers: 0, borneCible: 1 },
    { de: 2, borne: 1, vers: 0, borneCible: 1 }
  ]
}

Enregistre le fichier, recharge la page du simulateur. Le nouveau circuit apparaît dans la librairie.

Méthode recommandée : construis d'abord ton circuit dans le simulateur, exporte-le en JSON, puis recopie le contenu dans circuit.js en convertissant les identifiants en indices. Tu éviteras les erreurs de coordonnées et de bornes.

Exporter son circuit

Après avoir construit un circuit sur la plaque, tu peux l'exporter pour l'ajouter à la librairie.

  1. Construis le circuit dans le simulateur.
  2. Clique sur Exporter dans la barre d'outils.
  3. Un fichier JSON est téléchargé.
  4. Ouvre ce fichier pour voir sa structure.
{
  "version": "1.0",
  "date": "2025-10-09T14:30:00Z",
  "components": [
    { "id": "comp_1", "type": "battery",  "x": 100, "y": 200, "value": 9 },
    { "id": "comp_2", "type": "resistor", "x": 300, "y": 200, "value": 100 }
  ],
  "connections": [
    { "from": "comp_1", "fromTerm": 0, "to": "comp_2", "toTerm": 0 },
    { "from": "comp_2", "fromTerm": 1, "to": "comp_1", "toTerm": 1 }
  ]
}

Pour intégrer ce circuit à la librairie, convertis les identifiants en indices. Le premier composant du tableau devient l'indice 0, le deuxième l'indice 1, et ainsi de suite. Puis remplace les noms de champs components et connections par composants et connexions.

Erreurs fréquentes

Symptôme Cause Correction
Le circuit ne s'affiche pas Virgule manquante ou guillemet mal fermé Ouvre la console F12, corrige la ligne indiquée
Le circuit s'affiche partiellement Un indice de connexion dépasse la taille du tableau Vérifie que chaque de et vers existe
Deux composants se superposent Positions identiques en x et y Décale d'au moins 80 pixels
Un composant apparaît comme une résistance Le type n'existe pas Vérifie l'orthographe dans la liste des types
Valeurs absurdes à la simulation Le circuit n'est pas fermé, ou une borne a deux connexions Trace le circuit à la main sur papier avant de le coder
Circuit dans la mauvaise catégorie Le champ categorie diffère Utilise exactement la même chaîne que les autres circuits
Charger un circuit plante Valeur négative là où il faut du positif Résistances et tensions strictement positives

Quiz

Chaque module dispose d'un quiz de dix questions. Les explications apparaissent après chaque réponse. Le seuil de validation est de sept sur dix.

Les résultats sont conservés localement. Ils permettent de suivre sa progression dans le temps, et de comparer ses scores entre les modules.
