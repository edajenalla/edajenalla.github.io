# ⚡ Laboratoire Virtuel d'Électrotechnique

Laboratoire virtuel pour les TP d'électrotechnique à l'ENSET d'Antsiranana.

## 📋 Description

Projet de mémoire de licence STI. Simulateur de circuits électriques accessible dans le navigateur, gratuit, fonctionnant hors-ligne.

## 🚀 Fonctionnalités

- Module DC complet (5 composants, 5 TP)
- Module AC complet (oscilloscope, Fresnel, puissances)
- Quiz interactif de 10 questions
- Application PWA installable
- Fonctionne hors-ligne

## 🛠️ Technologies

HTML5 · CSS3 · JavaScript ES6+ · SVG · Canvas · localStorage · Service Worker

## 📁 Structure

Voir l'arborescence complète dans le projet.

## 🚦 Installation

1. Cloner le dépôt
2. Ouvrir `index.html` dans un navigateur
3. Aucune installation requise
